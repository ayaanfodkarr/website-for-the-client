# Cool Air Enterprises — Official Website

A professional, premium multi-page website built for **Cool Air Enterprises**, a trusted HVAC and Air Conditioning service provider based in Mumbai, India.

## 🌐 Live Pages
- Home
- About Us
- Services
- Projects
- Contact

## ✨ Features
- 3D animated particle background using Three.js
- Fully responsive mobile-friendly design
- Smooth scroll reveal animations
- Glassmorphism card design
- Floating WhatsApp chat button
- Contact inquiry form with JS validation
- Google Maps integration
- Animated stats counter
- Fixed navbar with frosted glass effect on scroll

## 🛠️ Built With
- HTML5
- CSS3 (pure, no frameworks)
- Vanilla JavaScript
- Three.js (r128)
- Google Fonts (Bebas Neue, Syne, DM Sans)
